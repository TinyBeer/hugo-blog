`Proto3` 是 `Google Protocol Buffers`（Protobuf）的第三个版本，2016 年推出，是一种语言中立、平台中立、可扩展的结构化数据序列化机制，用于序列化结构化数据，常用于通信协议、数据存储等场景，相比 `Proto2` 更简洁、高效、跨语言兼容性更强。

<!--more-->

本文将介绍如何在 `go语言` 中对使用 `proto3` 定义的对象进行序列化和反序列化。

## 准备工作

### 安装 protoc

`protoc` 是官网提供的用于解析和编译 `.proto` 的工具，进入 [下载地址](https://protobuf.dev/downloads/) 根据需求跳转到对应下载界面进行下载。具体的下载和解压过程这里就不进行展开了。需要注意的是，完成解压后还需要将解压目录下的 `bin` 路径添加到环境变量中，以便系统识别 `protoc` 命令

### 安装插件

`protoc` 需要使用 `protoc-gen-go` 插件辅助将 `.proto` 文件编译生成 `golang` 代码。

```bash
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
```

## 语法说明

`proto3` 基础语法可以参考 [传送门](/hugo-blog/note/proto3/)，更详细的说明请参考 [官方文档](https://protobuf.dev/programming-guides/proto3/)。

## 操作示例

### 工程准备

首先我们准备一个空的 `go` 工程:

```bash
mkdir proto_example
cd proto_example

go mod init proto_example
```

### 添加 proto 文件

```bash
mkdir proto
touch proto/user.proto
```

在 `user.proto` 添加如下内容：

```proto
syntax = "proto3";

option go_package = "proto_example/proto/gen/proto_user";

// User
message User {
  uint64 id   = 1;
  string name = 2;
  uint32 age  = 3;
}
```

### 编译 proto 文件

创建编译结果存放路径：

```bash
makedir proto/gen
```

执行一下命令生成 `go` 代码：

```bash
protoc --proto_path=proto --go_out=proto/gen --go_opt=paths=source_relative proto/user.proto
```

- `--proto_path（别名 -I）`：指定 `proto` 路径，`protoc` 会在指定路径下寻找相关的 `proto` 文件。可以通过添加多个 `--proto_path` 实现指定多个文件路径。
- `--go_out`：指定代码生成路径，`protoc` 会将编译结果存放在该路径下。
- `--go_opt=paths=source_relative`：指定输出文件与输入文件放在相同的相对目录中。例如，一个 `protos/foo.proto` 输入文件会产生一个位于 `protos/foo.pb.go` 的输出文件。
- 最后一个参数是要编译的 `proto` 文件，可以使用空格间隔添加多个文件。

执行完成后我们可以在 `proto/gen` 路径下看到一个新的文件 `user.pb.go` 文件，这就是 `proto` 的编译结果：

```golang
// Code generated by protoc-gen-go. DO NOT EDIT.
// versions:
// 	protoc-gen-go v1.36.5
// 	protoc        v3.20.1
// source: user.proto

package proto_user

import (
	protoreflect "google.golang.org/protobuf/reflect/protoreflect"
	protoimpl "google.golang.org/protobuf/runtime/protoimpl"
	reflect "reflect"
	sync "sync"
	unsafe "unsafe"
)

const (
	// Verify that this generated code is sufficiently up-to-date.
	_ = protoimpl.EnforceVersion(20 - protoimpl.MinVersion)
	// Verify that runtime/protoimpl is sufficiently up-to-date.
	_ = protoimpl.EnforceVersion(protoimpl.MaxVersion - 20)
)

// User
type User struct {
	state         protoimpl.MessageState `protogen:"open.v1"`
	Id            uint64                 `protobuf:"varint,1,opt,name=id,proto3" json:"id,omitempty"`
	Name          string                 `protobuf:"bytes,2,opt,name=name,proto3" json:"name,omitempty"`
	Age           uint32                 `protobuf:"varint,3,opt,name=age,proto3" json:"age,omitempty"`
	unknownFields protoimpl.UnknownFields
	sizeCache     protoimpl.SizeCache
}
...
```

可以看到这个文件的包名为 `proto_user`，这是我们通过 `proto3` 语法 `option go_package = "proto_example/proto/gen/proto_user";` 指定的。

## 序列化/反序列化

我们在根目录添加 `main.go` 文件进行序列化/反序列化操作：

```bash
touch main.go
```

```golang
package main

import (
	"log"
	proto_user "proto_example/proto/gen"

	"google.golang.org/protobuf/proto"
)

func main() {
	user := &proto_user.User{
		Id:   1,
		Name: "tom",
		Age:  18,
	}

	// 序列化 user
	pbs, err := proto.Marshal(user)
	if err != nil {
		log.Fatal(err)
	}
	// 反序列化到 user2
	user2 := new(proto_user.User)
	err = proto.Unmarshal(pbs, user2)
	if err != nil {
		log.Fatal(err)
	}

	log.Println(user)
	log.Println(user2)
}
```

在运行代码前，我们需要先解决一下依赖问题：

```bash
go mod tidy
```

运行代码：

```bash
go run .
2026/02/25 12:09:52 id:1  name:"tom"  age:18
2026/02/25 12:09:52 id:1  name:"tom"  age:18
```

## 其他

> [!NOTE]
> 虽然使用 `proto3` 序列化对象使用更少的空间存储对象，但是相较于使用 `json` 序列化会失去可读性。

修改一下 `main.go` 对比一下使用 `proto3` 和 `json` 序列化得到的结果：

```golang
package main

import (
	"encoding/json"
	"fmt"
	"log"
	proto_user "proto_example/proto/gen"

	"google.golang.org/protobuf/proto"
)

func main() {
	user := &proto_user.User{
		Id:   1,
		Name: "tom",
		Age:  18,
	}

	// proto 序列化 user
	pbs, err := proto.Marshal(user)
	if err != nil {
		log.Fatal(err)
	}

	// json 序列化 user
	jbs, err := json.Marshal(user)
	if err != nil {
		log.Fatal(err)
	}

	fmt.Println("proto3 序列化结果:")
	fmt.Printf("长度: %d 字节\n结果 %x\n", len(pbs), pbs)
	fmt.Println("json 序列化结果:")
	fmt.Printf("长度: %d 字节\n结果 %x\n", len(jbs), jbs)
}
```

执行：

```bash
go run .
proto3 序列化结果:
长度: 9 字节
结果 08011203746f6d1812
json 序列化结果:
长度: 30 字节
结果 7b226964223a312c226e616d65223a22746f6d222c22616765223a31387d
```

可以看到使用 `proto3` 序列化的结果长度显著小于 `json` 序列化结果。
